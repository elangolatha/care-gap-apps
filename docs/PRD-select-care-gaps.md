# Selecting care gaps

**Owner:** Hemalatha Elango | **Status:** Draft | **Version:** 0.1

## Problem
Gap lists go stale when providers do not select a gap at the point of care.

## User Story
As a primary care provider, I want to select a care gap to be addressed during the visit, so that the gap can be submitted.

## Acceptance Criteria

```gherkin
Given a care gap is shown
Then I should be able to select
And submit
```
